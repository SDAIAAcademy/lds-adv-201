# المختبر 3.3 · تكلفة الخيارات الأربعة

تقدير تكاليف أربعة خيارات: تبني في جدول البيانات التكلفة الإجمالية للملكية على ثلاث سنوات لكل خيار، وتضيف البنود التي أغفلتها عروض الأسعار، وتحسب المنافع وصافي القيمة

اليوم 3 · الجلسة 3: الخيارات الأربعة والتكلفة الإجمالية للملكية

### ستخرج من هذا المختبر بـ

- التكلفة الإجمالية للملكية (total cost of ownership, TCO) على ثلاث سنوات لكل خيار من الأربعة، مرتين: كما في عرض السعر، ومع البنود الغائبة.
- المنافع السنوية لكل خيار من نتائج التجربة وخط الأساس (baseline)، بالصيغ.
- ترتيب الخيارات بصافي القيمة (net value) على ثلاث سنوات.

## ما تحتاجه

[**cost_sheets.xlsx**الافتراضات، وورقة تكاليف لكل خيار من عرض سعره، والبنود الغائبة، وأنواع البنود](https://sdaiaacademy.github.io/lds-adv-201/labs/files/cost_sheets.xlsx) [**vendor_dataflows.csv**الخيارات الأربعة](https://sdaiaacademy.github.io/lds-adv-201/labs/files/vendor_dataflows.csv)

ورقة «الافتراضات» فيها خط الأساس المرجعي ونتائج التجربة المرجعية (الدقة 76.7% وحدها الأدنى 59.1%)، فلا يحتاج المختبر نتيجة سابقة لك. ابنِ نموذجك في ورقة جديدة في الملف نفسه، وكل رقم فيها صيغة تشير إلى خلية، لا رقم مكتوب. سياسة الذكاء الاصطناعي: ذكاء اصطناعي كامل، ويجب أن تشرح كل صيغة.

## الخطوات

### 1 · اقرأ أوراق التكاليف الأربع وتوقع حجم الطلب 5 د

لكل بند نوع: مرة واحدة، أو كل سنة، أو لكل موظف في السنة، أو لكل مسودة. الحجم السنوي في النطاق يكبر كل سنة بنسبة `growth`.

```
# ملف: الحجم في السنة y
الحجم(y) = in_scope_annual × (1 + growth)^y
```

### 2 · احسب تكلفة السنوات الثلاث لكل خيار بالصيغ 8 د

| الخيار | السنة 0 (مرة واحدة) | السنة 1 | السنة 2 | السنة 3 | المجموع |
| --- | --- | --- | --- | --- | --- |
| A |  |  |  |  |  |
| B |  |  |  |  |  |
| C |  |  |  |  |  |
| D |  |  |  |  |  |

البند «لكل مسودة» يُضرب في الحجم ونسبة الاستخدام؛ وفي D في نسبة الطلب العربي أيضًا، لأن المنصة لا تخدم إلا العربية.

### 3 · أضف بنود التقييم والمراجعة البشرية وصيانة المعرفة الناقصة 7 د

ورقة «بنود غائبة» تقول لكل بند أي الخيارات يلزمها. ومنها شرط عبور البوابة الذي كتبته في المختبر 3.2. أعد حساب المجموع، وضع الرقمين متجاورين.

### 4 · احسب المنافع السنوية لكل خيار من نتائج التجربة 5 د

```
# ملف: المنافع في السنة y
B و C: الحجم(y) × الاستخدام(y) × (الدقة × saving_when_usable × mean_handling − review_minutes) × cost_per_minute
D:     مثلها × ar_share
A:     الحجم(y) × (a_handling_cut + a_deflection) × mean_handling × cost_per_minute
```

المسودة الخاطئة لا توفر شيئًا وتكلف دقيقة مراجعة؛ لذلك تُطرح دقائق المراجعة من كل مسودة.

### 5 · رتّب الخيارات بصافي القيمة على ثلاث سنوات 3 د

صافي القيمة = مجموع المنافع − مجموع التكاليف مع البنود الغائبة. هل تغيّر الترتيب بعد إضافة البنود الغائبة؟

### 6 · حدد البند الغائب الذي يغيّر صافي القيمة أكثر، وتحقق بإزالته مؤقتًا 7 د

أزل البند من الخيارات التي يلزمها، وأعد الترتيب، ثم أعده. هل يقلب البند وحده الترتيب؟ اكتب الجواب بجملة يفهمها الشريك المالي.

### ✱ إضافي

أعد ترتيب الخيارات إن كانت دقيقة العمل الموفَّرة لا تتحول إلى ريالات إلا بنصف قيمتها، واكتب ما الذي يعنيه ذلك للتوصية.

## أسئلة تحقق

1. هل في نموذجك رقم مكتوب داخل صيغة لا يشير إلى خلية؟ أين؟
2. أي بند غائب غيّر الترتيب أكثر من غيره؟
3. لماذا لا يُحسب لـ D إلا الطلب العربي؟
